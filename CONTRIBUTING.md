# Contributing to Awesome STRK20

Thanks for helping grow the list of resources for building private apps on Starknet.

## Adding a resource

1. Fork the repo and edit `README.md`.
2. Add your entry to the most fitting section, keeping the existing format:
   ```
   - [Name](https://url) — One sentence describing what it is and why it's useful.
   ```
3. Keep the list alphabetical or logical within a section; don't duplicate existing entries.

## Guidelines

- **Public only.** Every link must resolve to a publicly accessible page. No internal docs, private repos, or gated resources.
- **Accurate and current.** Describe what the resource actually is. Avoid marketing language and unverified claims.
- **Link-check before submitting.** Confirm every URL returns a live page.
- **No secrets, ever.** Any code or config you contribute (including PoCs) must use placeholder values for keys, addresses, and endpoints. Never commit real private keys.
- **PoCs are reference implementations.** If you add example code, include a short README explaining its dependencies and that it is a learning reference.

## Reporting issues

Open an issue for broken links, outdated entries, or suggestions. Pull requests are preferred for concrete additions.
